# منصة تسجيل المتربصين

Application d'inscription aux stages, indépendante de Photo Challenge, Bataille navale et Chasse aux trésors.

- Interface : arabe, adaptée au téléphone et au PC.
- Compte organisateur et données : projet Supabase dédié `inscription-stages`.
- Formulaires publics par lien et QR code ; dossiers et justificatifs privés.
- Validation, paiement intégral, présence, export Excel et impression PDF.

Les fichiers à la racine et dans `assets/` constituent l'application publiée. Les sources sont conservées dans `source/`.

## Publication

Dans Settings → Pages, choisir « Deploy from a branch », branche `main`, dossier `/(root)`, puis Save.

La connexion s'effectue avec l'adresse e-mail et le mot de passe du compte organisateur existant. Aucun compte ChatGPT n'est nécessaire.
